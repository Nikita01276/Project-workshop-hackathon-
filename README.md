# СберАвтоподписка — Предсказание целевого действия

Модель предсказывает вероятность того, что пользователь совершит целевое действие (оставит заявку, закажет звонок) на сайте СберАвтоподписка.

**Метрика:** ROC-AUC = 0.719 (цель ≥ 0.65)

## Файлы проекта

| Файл | Описание |
|------|----------|
| `sber_auto_report.ipynb` | Итоговый аналитический отчёт: EDA + ML-модель + выводы |
| `sber_auto_analysis.ipynb` | Черновик EDA (разведочный анализ данных) |
| `sber_auto_model.ipynb` | Черновик обучения моделей |
| `predict.py` | Скрипт предсказания (принимает данные визита, возвращает 0/1) |
| `create_target.py` | Скрипт создания целевой переменной из ga_hits |
| `explore_ga_hits.py` | Скрипт разведки событий в ga_hits |
| `best_model.pkl` | Обученная модель LightGBM (ROC-AUC = 0.719) |
| `df_target.csv` | Датасет ga_sessions с добавленной целевой переменной |
| `df_clean.csv` | Очищенный датасет (после обработки пропусков и дубликатов) |

## Входные параметры

| Параметр | Тип | Описание | Пример |
|----------|-----|----------|--------|
| `utm_source` | str | Канал привлечения | `'google'` |
| `utm_medium` | str | Тип привлечения | `'cpc'`, `'smm'`, `'cpa'` |
| `geo_city` | str | Город пользователя | `'Moscow'` |
| `device_category` | str | Тип устройства | `'mobile'`, `'desktop'`, `'tablet'` |
| `visit_number` | int | Порядковый номер визита | `1`, `3`, `10` |
| `visit_time` | float | Время визита (секунды) | `43200` |
| `visit_date` | str | Дата визита | `'2021-11-10'` |

## Выходные данные

| Поле | Тип | Описание |
|------|-----|----------|
| `prediction` | int | 0 или 1 |
| `probability` | float | Вероятность целевого действия |
| `message` | str | Текстовое описание результата |
